# Portfolio requests and ownership

A portfolio visitor needs understandable projects, and an app user needs an
agent that finishes work, explains failures and stops when asked. These are
different jobs with coordinated owners. This sanitized register preserves the
accepted requests from 2026-10-14; it is not a claim that the portfolio is done.
Append dated decisions and progress receipts below instead of rewriting history.
Actual run evidence and private request sources remain in target-owned storage.

## Framework candidates

Checked against primary sources on 2026-10-14. Every own-portfolio result is
**UNMEASURED**. These are research candidates, not new kit dependencies.

| Candidate | Released evidence / fit | Decision before a target benchmark |
|---|---|---|
| [GEPA](https://github.com/gepa-ai/gepa) | MIT Python package; optimizes prompts/configuration with evaluator adapters and metric-call budgets. | First comparison candidate where prompt/tool policy is the observed bottleneck. |
| [RRSI](https://github.com/google-research/rrsi) | Apache-2.0 Python research implementation; bounded recursive code/harness proposals with validation and held-out evaluation. | Structural-harness challenger after a baseline; never let candidates edit the protected evaluator. |
| [JIT-Agent](https://github.com/bingreeky/JIT) | [August 2026 paper](https://arxiv.org/abs/2608.25593); MIT runtime, separate Apache-2.0 checkpoint and upstream data terms. | Isolated per-task harness experiment; generated executable modules need constrained tool authority. |
| [AutoDesign](https://github.com/Yaxin9Luo/AutoDesign) | [August 2026 paper](https://arxiv.org/abs/2608.13560); MIT code, artifact/design skills; third-party assets separate. | Claude-owned artifact/design candidate. Not evidence for universal agent reliability. |
| [Evo²](https://arxiv.org/abs/2610.13025) | October 2026 weight/harness co-evolution paper. Official code and weights were not verified. | Research reference; release and software/model license unresolved. Do not substitute the unrelated genomics Evo 2. |
| [NeMo Data Designer](https://github.com/NVIDIA-NeMo/DataDesigner) | Apache-2.0 Python package; seed-based structured generation and validation. | Synthetic-input candidate; generated expected answers still need independent review. |

Native Windows installation, costs, security behavior and improvements on these
apps have not been verified for these candidates. Published benchmark scores
use different tasks and budgets; do not rank portfolio performance from them.
Follow [the bounded proof protocol](long-running-goals.md) and retain the
incumbent when a candidate does not meet the same-case acceptance criteria.
